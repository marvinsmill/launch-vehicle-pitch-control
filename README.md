
# Launch-Vehicle Pitch Control

## Project Overview
An educational control-systems project exploring
the mathematical modelling and feedback control
of a simplified launch vehicle's pitch dynamics.

## Objectives
- Derive the governing equations.
- Obtain a transfer-function model.
- Design and simulate a feedback controller.
- Evaluate stability and system response.

## Tools
- Python
- NumPy
- SciPy
- Matplotlib
- Git and GitHub

## Current Progress
Project setup and foundational study.

## Learning Outcomes
To be updated as the project develops.

## Disclaimer
This is an academic simulation project, not
a flight-ready rocket control system.
